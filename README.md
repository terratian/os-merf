# OS-MERF: Open-Source Megalithic & Evolutionary Research Framework

## I. Raison d’Être
Mainstream anthropocentric science asserts that ancient populations spent massive portions of their societal surplus to construct multi-ton, 3D interlocking polygonal masonry purely for "tombs." When run inside an economic simulator, this narrative falls apart due to rapid caloric bankruptcy. 

The staggering deployment of geotorsional and seismic-dissipative masonry across non-contiguous continents proves these structures were engineered to survive severe planetary dynamics. We build this framework to quantify that truth using hard physics, data science, and decentralized, un-biased research tools.
